# Relesio feedback

This is the public place to report bugs and suggest features for [Relesio](https://relesio.com). Relesio versions your frontend builds, manages your environments, and serves your files from a global CDN.

## What to file

- **Bugs** in the dashboard, the `relesio` CLI or the CDN: something that breaks or does not do what it says.
- **Feature requests**: something you need that Relesio does not do yet.

Choose **New issue** and pick a form. Search the open issues first; if someone has already filed yours, add a 👍 or a comment there.

## Before you post

Issues here are public. Never paste API tokens, passwords or private URLs.
If you found a security problem, do not open an issue. Write to us through the Contact link at [relesio.com](https://relesio.com).

## The code is not here

This repository holds feedback only. Relesio's source code is not published here.
